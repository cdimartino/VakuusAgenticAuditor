# Blitz on Steam build 26660232

Blitz has a fixed itinerary and a pick-based merchant. The coach reads the current route, enabled offers, and actual player state. It does not roll rewards or advance rooms. The following is an audit of the installed public beta, **not an end-to-end playtest**.

| Flow | Native behavior in this build | Coach coverage |
| --- | --- | --- |
| Unlock and difficulty | The lobby describes the unlock as playing one Ascension run. Blitz has a shared maximum across characters. A non-custom victory at the current maximum raises it, up to 5. The cumulative levels are Weary Traveler, Tight Belt, Tough Enemies, Deadly Enemies, Ascender’s Bane. Legacy saved levels are clamped. | A requested route explanation includes the current Blitz tier. Potion advice reads the actual belt; combat advice reads actual intents. Lobby controls, unlocks and saves are game-owned. |
| Opening and Ancient rooms | Each act starts at the Ancient. Neow’s Blitz opening presents 10 class cards, without upgrades, and requests 3. This is a grid selection, not three mutually exclusive single-card rewards. | The opening and grid are separate decision surfaces. Draft fixtures exercise the pictured Fool offer, combinations, partial selections and unknown models. Later Ancient offers use the existing visible-option handlers. |
| Travel and resume | Default per act: Ancient → monster → monster → merchant → elite → chest → rest → boss. One weak normal slot is generated before the regular pool; monster identities are not fixed. The top bar shows the line. Proceed advances along it; at the end it signals an act change. The saved-map constructor restores links rather than regenerating the template. | Room/reward context previews remaining room types from the current links. No left/right choice. A replaced map, fork, cycle or unrecognized room does not produce a fixed-route claim. An actual extra boss is retained; ordinary Blitz Ascension does **not** include Double Boss. |
| Fights | The base itinerary has four combat rooms per act. Gremlin Merc still attacks, but its theft callback returns immediately in Blitz, despite its Thievery power. | Ordinary visible attack/block/target advice is reused. The three known Merc moves have a mode-specific cue under detailed visible intent. The coach does not identify a future monster from its route slot. |
| Monster, elite and boss rewards | Base monster: three common card choices, plus a potion for non-weak encounters. Elite: three uncommon card choices and two **separate** relic rewards. Boss in acts 1/2: three rare card choices and potion. Act 3 boss is not replaced by this mode hook. No gold is added by these replacements. | The picker evaluates materialized cards; the rewards screen counts remaining enabled buttons. One claimed relic isn’t recommended again. Relic and potion advice uses actual identities and slots. Extra or altered rewards are not promised. |
| Later card improvements | Nonboss combat-origin card rewards in acts 2/3 sample one/up to two options respectively; only sampled cards that can upgrade are upgraded. No late Blitz upgrade for the first act, boss, or noncombat merchant card offer. | The coach distinguishes possible attempts from guaranteed upgrades and evaluates the displayed cards. No RNG call or prediction. |

The encounter ledger accounts for each native entry separately; catalog-only text does not establish a playable pack offer. |

Normal chest gold and its Spoils Map branch are bypassed. | Two visible enabled relics are described as successive picks, not an exclusive choice. | Camp | In the base line the next stop is the boss. Heal uses the actual rest amount (including game adjustments); Smith opens the ordinary cancelable upgrade picker. Custom and relic-provided actions may coexist. | The pre-boss comparison uses enabled Heal/Smith buttons, current HP and legal upgrades. Exclusions are generation filters, not grounds for discarding an actual visible modded, forced or saved offer. Foreign effects are not simulated. |

Multiplayer chest rules, votes and progression synchronization differ. The native game-over screen hides the gold score line. | Mode-specific room advice requires the audited profile, singleplayer transport, one player and a non-custom run without run modifiers. Installed content mods are **not** equivalent to custom run modifiers. An installed mod can still patch native behavior; there is no universal compatibility guarantee.
